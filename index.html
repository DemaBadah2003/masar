// 01 — about

I like building the whole thing, not just one layer.

I work across the full stack — React and Next.js on the front end, Laravel powering the API and business logic behind it. That combination lets me take a product from an idea on paper to something people can actually log into and use.

My focus is on clean, maintainable code and interfaces that feel considered — whether that's a dashboard, an e-commerce storefront, or a platform built to help people find help faster.

// 06 — faq

Common questions

What's your main stack?

React and Next.js for the frontend, Laravel and MySQL for the backend. I'm comfortable owning both sides of a project.

Do you work with existing codebases?

Yes — I can join a project partway through, whether that means adding features, fixing bugs, or refactoring an existing React or Laravel app.

How long does a typical project take?

A landing page usually takes 3–5 days. A full-stack app depends on scope, but most land between 3–6 weeks — I'll give you a clear estimate after we scope it together.

Are you available for remote, freelance work?

Yes. I work remotely and communicate in Arabic or English, whichever is easier for you.
